# Garmin Dashboard

A personal fitness dashboard for your Garmin Connect data. Upload your CSV exports and see beautiful charts, stats, and insights — all processed locally in your browser.

**[Live Demo →](https://sdooodly.github.io/garmin-dashboard/)**

## Features

- Upload Garmin Connect activity CSVs (or try the built-in demo data)
- Health data support: steps, heart rate, sleep, stress
- 11 interactive charts (timeline, pace progression, weekly volume, and more)
- Auto-generated insights about your training trends
- Date range and activity type filters
- Dark theme, responsive, 100% client-side

## Getting Started

```bash
npm install
npm run dev
```

## How to Export Your Garmin Data

1. Go to [connect.garmin.com/modern/activities](https://connect.garmin.com/modern/activities)
2. Scroll to load all activities
3. Click **Export CSV** in the top-right

For health data (steps, sleep, stress, HR), go to Health & Performance → Reports and export each metric.
